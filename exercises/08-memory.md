# Exercises: Memory

Lesson: [Memory](../docs/lessons/08-memory.md). Solutions: `solutions/s08_memory.py`.

## Exercise 1

Pin a second fact: "The user has a nut allergy." Add thirty short turns. Check that both pinned facts are still in the window.

## Exercise 2

With `max_tokens=40` and no pins, add ten turns of "hello there friend". How many turns fit in the window? Work it out, then check.

## Exercise 3

Write a memory that also keeps at most the last four turns, whatever their size.
