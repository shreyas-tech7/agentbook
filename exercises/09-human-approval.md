# Exercises: Human approval

Lesson: [Human approval](../docs/lessons/09-human-approval.md). Solutions: `solutions/s09_human_approval.py`.

## Exercise 1

Mark `list_files` as risky too. With an approver that always says no, at which step does the run stop?

## Exercise 2

Write an approver that allows a delete only for file names that end in ".log".

## Exercise 3

Add a risky `send_email` tool. Run it with no approver. What happens, and how do you know no email went out?
