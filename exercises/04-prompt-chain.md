# Exercises: Prompt chain with gates

Lesson: [Prompt chain with gates](../docs/lessons/04-prompt-chain.md). Solutions: `solutions/s04_prompt_chain.py`.

## Exercise 1

Add a third step that translates the title into French. Give it a gate that rejects an empty reply. Script all three replies.

## Exercise 2

The title step returns "Launch moves to March." with a final dot. Which gate fails, and how many calls were made?

## Exercise 3

Write a gate that requires the summary to mention the word "March". Use it in place of the summary gate.
