# Exercises: Retrieval as a tool

Lesson: [Retrieval as a tool](../docs/lessons/12-retrieval.md). Solutions: `solutions/s12_retrieval.py`.

## Exercise 1

Add a document `d4` about sick leave. Check that a search for "sick leave" returns `d4` first.

## Exercise 2

The model searches for "pizza", gets no results and still cites `[d1]`. What is the stop reason?

## Exercise 3

A search for "leave" matches `d1` and `d2` equally. Which one comes first, and why?
