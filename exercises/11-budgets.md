# Exercises: Budgets and stop rules

Lesson: [Budgets and stop rules](../docs/lessons/11-budgets.md). Solutions: `solutions/s11_budgets.py`.

## Exercise 1

Run the example with `max_steps=1`. What is the stop reason, and how many calls happen?

## Exercise 2

Find the smallest `max_tokens` that still lets the example finish with `done`.

## Exercise 3

Use a fake clock where each call takes 7 seconds. The time limit is 20 seconds. How many calls happen before the stop?
